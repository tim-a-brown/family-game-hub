How to play

Goal

Be the first to 20 lore. Gain lore by questing with characters.

Turn structure

Ready → Set (draw, optionally ink) → Do (play cards, quest, challenge).

Using this counter

Tap + / − to adjust lore. Tap the ×1 chip to change the step (1 / 2 / 3). Long-press the diamond to set an exact value. Tap a player's name to rename them.

Orientation

Scores across from you appear upside-down so each player reads from their own seat.
