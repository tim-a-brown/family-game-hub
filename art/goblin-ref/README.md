# Goblin Defenders: reference shots (not public: art/** is in hosting.ignore)

Tim's screenshots of the original game (Goblin Defenders: Battles of Steel 'n' Wood, Qumaron), for look and feel only.
Our game uses our own art, drawn to match this style. Delete this folder before the branch is merged.

- jungle-video-*.jpg: frames from Tim's screen recording (a jungle road level). 0.3 shows the tower menu (sell for 5
  coins, upgrade for 15, damage 4 -> 11, range circle); 11.5 shows the build grid while placing a tower.
- snow-level.jpg, desert-level.jpg: road levels in other biomes, with special towers (tesla coil, frost crystal,
  acid barrel, mortar, spiked dome) and enemies (purple wraiths, spiders), a goblin mech hero bottom-right.
- canyon-maze-level.jpg: an open-field level where walls of crossbow towers form the maze.
